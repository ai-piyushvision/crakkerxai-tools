How a conversion works

  1. Open the tool that matches your task and choose files from your device.
  2. Set the available options, such as page ranges, output format or image dimensions.
  3. Run the conversion and save the result using the download link. For the eight public converters, processing runs in your browser.

The browser tools do not upload selected file contents to the conversion server. Account, feedback, advertising and optional AI Updates features use separate website services described in the Privacy Policy.

COMMON QUESTIONS

Before you start

Do I need to install software?

No. Open a tool in a modern browser, choose your files and download the result. JavaScript must be enabled.

Are my PDF and image files uploaded?

The eight public conversion tools process selected file contents locally in your browser. The files are not sent to the conversion server by the conversion code.

What is the free conversion input limit?

The public browser converters enforce a combined 50 MB input limit per task. Individual tools also have format, page-count or image-dimension limits.

Where can I get help?
