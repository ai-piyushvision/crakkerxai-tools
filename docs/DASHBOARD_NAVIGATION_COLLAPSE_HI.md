# Dashboard sidebar navigation and collapse update

## Sidebar destinations
The authenticated workspace now has nine in-dashboard destinations:
- Overview
- Analytics
- Reports & Activity
- My Files
- Resources
- All Tools
- Upgrade Plan
- AI Updates
- Feedback & Help

All nine sidebar selections are buttons that switch the panel inside `/account/`. Selecting one of these destinations does not navigate away from the workspace or remove the sidebar.

The actual conversion-tool cards still open their dedicated converter pages. On those pages, signed-in users can use the shared **Dashboard** shortcut in the top header to return to `/account/?view=overview`.

## Collapse / expand
Use the chevron control beside the CrakkerXworld.AI logo in the sidebar. Collapsed state keeps the icons available and hides labels/search. The preference is remembered in browser local storage under `cx_dashboard_sidebar_collapsed`.

## Signed-in header
The shared header shows a **Dashboard** shortcut only when Supabase reports an authenticated session. It opens the Overview dashboard directly. The shortcut is available on the homepage, tool pages and informational pages generated by `scripts/generate-pages.mjs`.

## Verification
The project test suite checks that all nine navigation targets have matching dashboard panels, that the lower sidebar destinations are in-dashboard buttons, that the collapse control persists its state, and that the shared signed-in header exposes the Dashboard shortcut.
