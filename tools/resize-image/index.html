Resize images online by entering the pixel width you need. Use the aspect-ratio option to calculate the matching height automatically, or turn it off to set both dimensions. JPG, JPEG, PNG and WebP images are processed in your browser.

SUPPORTED FORMATS

Input: JPG, JPEG, PNG and WebP. Set width and optional height in pixels; each dimension can be from 1 to 12,000 pixels, subject to a 30-megapixel canvas limit. Multiple results are packaged in a ZIP file.

PRIVATE PROCESSING

Selected file contents are processed locally in your browser. This conversion tool does not upload your files to the conversion server.

INPUT SIZE

Up to 50 MB combined input per task. Browser memory and document complexity can affect processing time.

How to use Resize Image

  1. Choose one or more JPG, JPEG, PNG or WebP images.
  2. Enter the desired width in pixels. Keep the aspect-ratio option enabled to calculate height automatically, or enter both dimensions.
  3. Click Resize Images and download the resized image or ZIP file.

Supported formats and options

Input: JPG, JPEG, PNG and WebP. Set width and optional height in pixels; each dimension can be from 1 to 12,000 pixels, subject to a 30-megapixel canvas limit. Multiple results are packaged in a ZIP file.

When this tool is useful

  • Prepare photos for forms, portals or websites that require specific dimensions.
  • Reduce large image dimensions before sharing or uploading elsewhere.
  • Create consistently sized image files while preserving aspect ratio.

A practical example

A 2400 × 1600 photo resized to 1200 pixels wide becomes 1200 × 800 when aspect ratio is locked. Turn the lock off only when you intentionally need a different width and height.

Limitations to know before converting

JPG, PNG and WebP inputs are accepted. Each output dimension must be from 1 to 12,000 pixels and the canvas cannot exceed 30 megapixels. The output keeps PNG or WebP when the source filename uses that extension; other supported images are exported as JPG.

Common questions about Resize Image

Can I resize an image by pixels?

Yes. Enter the target width and, when aspect ratio is disabled, the target height in pixels.

Can I keep the original aspect ratio?

Yes. Keep the aspect-ratio checkbox enabled and the height is calculated automatically.

Which formats can I resize?

JPG, JPEG, PNG and WebP images are supported.

Can I resize several images together?

Yes. Select multiple images and download the resized results in a ZIP file.
