Rotate PDF pages online when a document is sideways or upside down. Choose 90°, 180° or 270° clockwise rotation, apply it to the entire PDF or enter specific page numbers, and download the updated document. The original PDF is not overwritten.

SUPPORTED FORMATS

Input: one PDF file up to 50 MB. Rotation options: 90°, 180° or 270° clockwise. Leave the page field blank to rotate all pages, or enter page numbers and ranges to rotate selected pages.

PRIVATE PROCESSING

Selected file contents are processed locally in your browser. This conversion tool does not upload your files to the conversion server.

INPUT SIZE

Up to 50 MB combined input per task. Browser memory and document complexity can affect processing time.

How to use Rotate PDF

  1. Choose the PDF you want to adjust.
  2. Select 90°, 180° or 270° clockwise. Leave Pages blank to rotate all pages, or enter a selection such as 1,3-5.
  3. Click Rotate PDF and download the updated document.

Supported formats and options

Input: one PDF file up to 50 MB. Rotation options: 90°, 180° or 270° clockwise. Leave the page field blank to rotate all pages, or enter page numbers and ranges to rotate selected pages.

When this tool is useful

  • Correct sideways pages in a scanned PDF.
  • Turn upside-down pages in a document or report.
  • Rotate only selected pages without changing the rest of the PDF.

A practical example

When page 4 is sideways but the other pages are already upright, enter 4 and choose 90° clockwise. Only that page receives the rotation change.

Limitations to know before converting

One PDF up to 50 MB is accepted. Available increments are 90°, 180° and 270° clockwise; arbitrary angles are not supported. Rotation changes page orientation metadata rather than repainting the page contents.

Common questions about Rotate PDF

Can I rotate only one PDF page?

Yes. Enter the page number in the Pages field.

Which rotation angles are available?

You can rotate pages by 90°, 180° or 270° clockwise.

Does rotation reduce PDF quality?

The tool updates page rotation metadata rather than re-rendering page content.

Can I rotate all pages at once?

Yes. Leave the Pages field blank to rotate every page.
