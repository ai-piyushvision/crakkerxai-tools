Use this free merge PDF online tool to combine multiple PDF files into one document. Select at least two PDFs, arrange the files in the required order, and merge their pages into a single downloadable PDF. Processing takes place in your browser.

SUPPORTED FORMATS

Input: two or more standard PDF files with a combined size of up to 50 MB. Output: one merged PDF. Password-protected or damaged PDFs may not open.

PRIVATE PROCESSING

Selected file contents are processed locally in your browser. This conversion tool does not upload your files to the conversion server.

INPUT SIZE

Up to 50 MB combined input per task. Browser memory and document complexity can affect processing time.

How to use Merge PDF

  1. Select at least two PDF documents.
  2. Move the selected files up or down until they are in the required order.
  3. Click Merge PDFs and download the combined PDF when it is ready.

Supported formats and options

Input: two or more standard PDF files with a combined size of up to 50 MB. Output: one merged PDF. Password-protected or damaged PDFs may not open.

When this tool is useful

  • Combine separate report chapters or project documents.
  • Join scanned PDF documents and forms into one file.
  • Put invoices, statements or supporting documents in the required order.

A practical example

Select a project brief, its appendix and a supporting schedule in that order. The output places every page from the brief first, followed by the appendix and then the schedule.

Limitations to know before converting

At least two standard PDFs are required and their combined input size must not exceed 50 MB. Damaged or password-protected files may fail to open. Review the merged file before sending it, especially when the source documents contain forms or other interactive elements.

Common questions about Merge PDF

How many PDF files can I merge?

Select at least two PDFs. The combined input size limit is 50 MB per task.

Can I change the order before merging?

Yes. Use the up and down controls beside each selected file.

Can I merge password-protected PDFs?

Password-protected PDFs are not supported by this tool.

Are my PDFs uploaded?

No. PDF merging runs locally in your browser.
