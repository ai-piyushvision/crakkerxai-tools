Extract pages from a PDF online without changing the original file. Enter individual page numbers, comma-separated selections or ranges such as 1,3,5-7, then create a new PDF containing only the pages you selected. The page order follows your selection.

SUPPORTED FORMATS

Input: one PDF file up to 50 MB. Enter page numbers such as 1,3,5-7 or type all to select every page. The output is a new PDF containing the selected pages.

PRIVATE PROCESSING

Selected file contents are processed locally in your browser. This conversion tool does not upload your files to the conversion server.

INPUT SIZE

Up to 50 MB combined input per task. Browser memory and document complexity can affect processing time.

How to use Extract PDF Pages

  1. Choose the PDF document you want to work with.
  2. Enter page numbers or ranges, for example 1,3,5-7. Enter all to keep every page.
  3. Click Extract Pages and download the new PDF containing the selected pages.

Supported formats and options

Input: one PDF file up to 50 MB. Enter page numbers such as 1,3,5-7 or type all to select every page. The output is a new PDF containing the selected pages.

When this tool is useful

  • Save only the pages needed from a long report or manual.
  • Create a smaller PDF containing selected forms or attachments.
  • Separate chosen pages before sharing or combining them with another PDF.

A practical example

Entering 1,3,5-7 creates a new PDF with source pages 1, 3, 5, 6 and 7, in that selected order.

Limitations to know before converting

The tool works with one PDF up to 50 MB. Every requested page number must exist in the source document. Damaged or password-protected PDFs may not open; the original source file is not changed.

Common questions about Extract PDF Pages

How do I extract multiple PDF pages?

Enter page numbers separated by commas, for example 1,3,6.

Can I extract a page range?

Yes. Enter a range such as 2-5, or combine ranges and individual pages like 1,3,5-7.

Can I extract all pages?

Yes. Enter all or leave the page selection blank.

Does extraction change my original PDF?

No. The tool creates a new PDF and leaves your original file unchanged.
