Frequently Asked Questions

Practical answers about the eight PDF and image tools.

Using the converters

Do I need to install an application?

No. The eight public converters run in a modern browser with JavaScript enabled. Choose a tool, select files and download the result.

Are my PDF and image files uploaded to a server?

The current browser converter code processes selected file contents on your device. It does not send those contents to the conversion server. This statement applies to the eight PDF and image converters, not to account, feedback or other website features that may process information separately.

What is the standard file-size limit?

The standard limit is 50 MB of combined input per conversion task. A tool may also have a page-count, dimension or file-count limit. Read the Supported formats and options section on the tool page before starting.

Which image formats are supported?

The image tools accept JPG/JPEG, PNG and WebP. Output formats depend on the selected tool: Images to PDF creates PDF; Convert Image can export PNG, JPG or WebP; Compress Image exports WebP or JPG; Resize Image keeps PNG or WebP where indicated by the input filename and otherwise exports JPG.

Can I use a password-protected PDF?

Password-protected PDFs may not open in the current PDF tools. Remove the password only when you are authorized to do so, then try the resulting PDF.

How are multiple output images downloaded?

When a task creates more than one output image, the files are packaged in a ZIP download. A single selected page or single output image may download as an individual file.

Will a PDF converted to PNG keep selectable text?

No. PDF-to-PNG/JPG converts each selected page into a flat image. The image does not retain selectable text, PDF links or vector editing.

Can I change the order of files before conversion?

Yes, on tools that accept multiple source files, use the up and down controls in the selected-file list to arrange the processing order.

Do I need an account to use the tools?

The core PDF and image converters can be used without creating an account. Account features are optional.

Where do I report a problem or request a feature?

Use the Contact Us page or send a message through the Feedback & Bug Reports form.
