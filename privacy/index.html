Privacy Policy

What the website processes, what stays in your browser and how to contact us about your data.

Effective date: 20 November 2026

1. Files used with the eight conversion tools

The eight public PDF and image converters run in the browser using JavaScript libraries. The converter code reads selected files in the page, creates the output in browser memory and makes a download link. It does not send the selected file contents to the conversion server. Temporary working data and the generated download URL remain in the browser while the page and result are in use; the page revokes the download URL when the result is cleared or the page is unloaded. Your browser and device may retain their own temporary memory or cache data.

The standard browser tool limit is 50 MB of combined input per task. PDF to PNG also supports up to 120 pages per task. Image canvases have a 30-megapixel safety limit and dimension limits; browser memory and file compatibility also matter. See each tool page for its specific formats and limits.

2. Local activity history and preferences

If you complete a conversion, the dashboard can save a small activity record in local browser storage: tool name, output filename, output size and completion time. The activity list is stored on that browser and is not the converted file or a cloud copy. The theme preference, collapsed-sidebar setting and daily guest conversion counter may also be saved in local browser storage. The selected dashboard view can be kept in session storage for the current tab session. These values are settings or usage counters, not copies of the converted files. Clearing browser site data can remove the local records and preferences.

3. Contact and feedback submissions

When you submit the Feedback & Bug Reports form, the site sends the name, email address, contact number, optional WhatsApp number, category, subject, message, optional page URL and consent choice to the website's feedback endpoint. The endpoint stores a feedback record in the configured service database. It creates a one-way hash of the request IP for abuse-rate limiting; the hosting provider may separately process connection IP and request logs. If email notifications are configured, a message containing the submission is sent to the operator through the configured email delivery provider. The form is unavailable when the server-side database is not configured.

Do not include passwords, one-time codes, payment-card details or confidential file contents in a support message. We do not state a fixed deletion period for feedback records. For a data request, use the Contact Us page and identify the submission as clearly as possible.

4. Accounts and authentication

Account features use Supabase Auth when enabled. Supabase may process email addresses, phone numbers, authentication identifiers and account metadata needed to sign in. Phone verification may use the configured MSG91 service, which receives the phone number and verification information needed to send or confirm a one-time code. Authentication sessions may be kept in browser storage so that you remain signed in. To enforce the account password policy, the service database also stores the date of the last password change and whether an initial or 60-day password update is still required. It does not store the plain-text password. New OTP-created accounts must set a password before entering the workspace; passwords must be refreshed after 60 days. For pre-existing accounts, the original password-change date was not recorded, so the first rollout asks those users to set a fresh password once to establish an accurate date.

5. Payments and membership

Optional paid membership checkout uses Razorpay when payment configuration is enabled. Razorpay processes the payment method and payment details. The website's server stores order and verification references, plan and membership status, amounts and limited payment-history information needed to verify a purchase and show account history. Payment options may be unavailable when the required configuration is not active.

6. Hosting, advertising and third-party services

The website is hosted through Cloudflare. The website may load Google AdSense advertising code; an ad unit is only inserted on a converter result view when a display slot has been configured. Google and its partners may process device, cookie, advertising and measurement information under their own policies. We do not intentionally send the files selected for conversion to Google advertising services. Read Google's advertising technology information and Google's Privacy Policy.

The optional AI Updates page requests public RSS/Atom feed data from the configured Python service and displays publisher-provided titles, excerpts, dates and source links. Opening an original story takes you to the publisher's website, which has its own privacy practices. PDF and image processing libraries are downloaded as part of the website; they process the selected files in the browser.

7. Cookies and your choices

Local browser storage is used for settings, authentication state and the activity list described above. Google advertising technologies may use cookies or similar identifiers when advertising is active. You can manage or clear site data and cookies through your browser settings. This website does not currently expose a custom cookie-preference panel; legal consent requirements and Google's consent tools may depend on the visitor's location and the advertising configuration.

8. Policy changes

We may update this notice when the website or its service providers change. The effective date at the top identifies this version. Please review this page periodically.

9. Contact

Use the Contact Us page to reach the support form. We do not publish a street address or direct support email on this page.
