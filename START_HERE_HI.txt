PRODUCTION DEPLOYMENT

1. Deploy Python API using root render.yaml or backend/Dockerfile.
2. Test Python API /health and /api/search?q=pdf%20to%20png.
3. In Cloudflare Worker environment variables, add PYTHON_API_URL=https://YOUR-PYTHON-API-HOST (no trailing slash) and PYTHON_API_SECRET (same value as Python INTERNAL_API_KEY).
4. Deploy Cloudflare frontend/Worker again.
5. Verify homepage, all 8 tool pages, conversions, search, account and pricing.

SEO: sitemap is /sitemap.xml. Submit it in Google Search Console and Bing Webmaster Tools after deployment. Indexing/ranking is not instant or guaranteed.

ARCHITECTURE NOTES
- JavaScript is used for UI and interaction.

- Existing Supabase/Razorpay account/payment endpoints remain Cloudflare Worker JavaScript in this release.
- Files are uploaded over HTTPS to Python and processed in memory; privacy policy has been updated.
